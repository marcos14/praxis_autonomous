# 2. Criando uma demanda

1. Em `Nova demanda`, escolha o projeto e cole o PRD do time de produto (ou o texto do chamado). Não precisa ser detalhado — é papel do analista descobrir o que falta.
2. O analista roda em **modo somente leitura** sobre o código e gera perguntas objetivas. Nada é alterado nessa etapa.
3. Demandas também podem chegar sozinhas pela API (integração com o sistema de chamados), usando um token de papel `operador`.
