# 4. Aprobando el plan

1. El card muestra el plan completo y la lista de fases (con dependencias y estimación de costo).
2. Usted puede reordenar, eliminar fases y marcar fases que exigen validación humana antes de ejecutarse.
3. **Aprovar** (Aprobar) coloca la demanda en la cola de ejecución. **Rejeitar com comentário** (Rechazar con comentario) genera un nuevo plan considerando su feedback.
