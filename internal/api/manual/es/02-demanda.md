# 2. Creando una demanda

1. En `Nova demanda` (Nueva demanda), elija el proyecto y pegue el PRD del equipo de producto (o el texto del ticket). No necesita ser detallado — es rol del analista descubrir lo que falta.
2. El analista se ejecuta en **modo solo lectura** sobre el código y genera preguntas objetivas. Nada se altera en esta etapa.
3. Las demandas también pueden llegar solas por la API (integración con el sistema de tickets), usando un token de rol `operador`.
