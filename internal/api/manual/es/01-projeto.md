# 1. Registrando un proyecto

1. Vaya a `Projetos → Cadastrar projeto` (Proyectos → Registrar proyecto) e informe la carpeta (debe ser un repositorio git) y la rama principal. El botón **Procurar…** (Explorar…) al lado del campo abre un navegador de las carpetas **de la máquina donde se ejecuta Praxis** (no la suya), señalando cuáles ya son repositorios git.
2. Defina los parámetros o déjelos heredar del global: motor, máximo de correcciones, máximo de fases nuevas, budget, gates.
3. Los **gates** son los comandos de validación (build, lint, test). Una fase solo se concluye con todos en verde — dedíqueles atención.
4. En la sección **Acesso** (Acceso) del proyecto usted define quién ve el proyecto (grupos de usuarios y/o usuarios). Nada seleccionado = visible para todos — ver la sección "Usuarios, roles y acceso a proyectos".
