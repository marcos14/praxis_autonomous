# El flujo de una demanda

El ciclo de una demanda es:

**Llega el PRD → El analista lee el código → Usted responde preguntas → Plan por fases → Usted aprueba → Se ejecuta en el worktree → Usted integra.**

Todo lo demás es automático. Usted solo interviene en tres momentos: **responder las preguntas**, **aprobar el plan** e **integrar (merge)**. El card en el kanban avisa cuando es su turno — y las notificaciones también.
