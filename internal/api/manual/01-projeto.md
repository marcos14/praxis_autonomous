# 1. Cadastrando um projeto

1. Vá em `Projetos → Cadastrar projeto` e informe a pasta (precisa ser um repositório git) e a branch principal.
2. Defina os parâmetros ou deixe herdar do global: motor, máximo de correções, máximo de fases novas, budget, gates.
3. Os **gates** são os comandos de validação (build, lint, teste). Uma fase só conclui com todos verdes — capriche neles.
