# 2. Creating a demand

1. In `Nova demanda` (New demand), choose the project and paste the PRD from the product team (or the text of the ticket). It does not need to be detailed — it is the analyst's job to find out what is missing.
2. The analyst runs in **read-only mode** over the code and generates objective questions. Nothing is changed at this stage.
3. Demands can also arrive on their own through the API (integration with the ticket system), using a token with the `operador` role.
