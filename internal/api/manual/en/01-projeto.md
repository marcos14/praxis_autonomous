# 1. Registering a project

1. Go to `Projetos → Cadastrar projeto` (Projects → Register project) and enter the folder (it must be a git repository) and the main branch.
2. Set the parameters or let them be inherited from the global ones: engine, maximum number of fixes, maximum number of new phases, budget, gates.
3. The **gates** are the validation commands (build, lint, test). A phase only completes with all of them green — take care when defining them.
4. In the **Acesso** (Access) section of the project you define who can see the project (user groups and/or users). Nothing selected = visible to everyone — see the section "Users, roles and project access".
