# 3. Answering the questions

1. The card stays in `Aguardando respostas` (Awaiting answers). Open it and answer — each question comes with context from the code and a suggestion from the analyst.
2. You can accept the suggestion with one click or write your own. A high-impact question changes the architecture of the solution: read it carefully.
3. Answered everything → click **Responder tudo e gerar plano** (Answer all and generate plan). The planner combines the PRD + your answers and assembles the phases.
