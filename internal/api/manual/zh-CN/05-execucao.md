# 5. 执行期间

- 每个需求都在**独立的 git 工作树**中运行，位于分支 `praxis/d<id>-<slug>`。你的 working tree 永远不会被碰到 —— 照常继续工作即可。
- 每个阶段：执行者 → gates（校验）→ 修复（如有需要）→ 评审者 → 提交到分支。可通过卡片上的实时日志跟踪。
- 你随时可以在卡片上 **pausar**（暂停）或 **cancelar**（取消）。暂停后可从中断处恢复。
- 需求**失败**了（例如：run 超出了引擎的 budget）？请修正原因 —— 比如在 `Motores`（引擎）界面提高 budget —— 然后使用卡片上的 **Tentar novamente**（重试）：需求会从失败的环节（分析、规划，或中断的那个阶段）恢复，不会丢失已经完成的工作。
- 引擎的额度用完了？Praxis 会切换到优先级中的下一个引擎，或者等待重置 —— 卡片会显示当前状态。
