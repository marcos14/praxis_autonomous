# 常见问题

- **两个需求可以改动同一个文件吗？** 可以 —— 各自在自己的分支上。冲突会在集成时出现；Kanban 会提前显示重叠提示。
- **数据保存在哪里？** 全部保存在 Praxis 的数据库中（在项目之外）：PRD、聊天、问题、计划、阶段、成本和日志。项目中只有分支上的提交。
- **成本呢？** 每个需求都有预算上限。超出后会暂停并提醒。Home（首页）按天、按项目显示花费。
- **某次运行超出预算，需求失败了。我的东西都丢了吗？** 不会。请调高引擎的预算（Motores（引擎）页面），然后点击卡片上的 **Tentar novamente（重试）** —— 需求会从失败的环节（分析、规划或被中断的阶段）继续。
- **可以在手机上使用或安装为应用吗？** 可以。当 Praxis 使用有效的 HTTPS 时，浏览器会提供**安装应用**（菜单底部；iPhone 上使用“分享 → 添加到主屏幕”）。在手机上，菜单位于 ☰ 后面，列表会在单独页面打开条目（← 返回），看板一次显示一列。Web IDE 仅限桌面。

- **不用盯着屏幕，怎么知道我的咨询已被回答？** 铃铛会在打开的标签页中提醒；如果你在 **我的账户 → 通知** 中启用了推送，即使关闭 Praxis，手机或电脑也会提醒你。只有项目的创建者会收到提醒。
