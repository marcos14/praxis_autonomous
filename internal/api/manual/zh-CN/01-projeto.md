# 1. 注册项目

1. 进入 `Projetos → Cadastrar projeto`（项目 → 注册项目），填写文件夹（必须是一个 git 仓库）和主分支。字段旁的 **Procurar…**（浏览…）按钮会打开一个浏览器，列出**运行 Praxis 的那台机器**上的文件夹（不是你本机的），并标出哪些已经是 git 仓库。
2. 设置各项参数，或让它们从全局继承：引擎、最大修复次数、最大新增阶段数、budget（预算）、gates（校验）。
3. **gates** 是验证命令（build、lint、测试）。一个阶段只有在全部通过时才算完成 —— 请认真设置它们。
4. 在项目的 **Acesso**（访问权限）区域，你可以定义谁能看到该项目（用户组和/或用户）。什么都不选 = 对所有人可见 —— 参见“Usuários, papéis e acesso a projetos（用户、角色与项目访问权限）”一节。
