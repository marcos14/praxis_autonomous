Home

Visão do mês: gastos, demandas ativas e o que precisa de você.

Kanban

Cada coluna é um status. Arraste um card para reordenar a prioridade; as transições de estado acontecem pelos botões do card.

Demandas

Cada demanda roda sozinha em sua branch. Abra o card para acompanhar as fases e o log ao vivo.

Nova demanda

Escolha o projeto e cole o PRD ou descreva o chamado. A demanda nasce como conversa — tudo fica registrado no chat até virar plano.

Consultas

Pergunte como o sistema se comporta — para elaborar PRDs, entender rotinas ou montar a estratégia de um cliente. O consultor analisa o código e responde em linguagem de negócio, sem expor código-fonte.

Selecione uma consulta à esquerda ou inicie uma nova.

Projetos

Cadastre a pasta do projeto e os parâmetros. O que não for definido aqui herda da configuração global.

Selecione um projeto à esquerda ou cadastre um novo.

Grupos de repositórios

Agrupe os repositórios de uma mesma solução (ex.: "Vulcano Chat"). Nas consultas, o primeiro projeto do grupo é o repositório principal e os demais entram como contexto extra. Um projeto pode participar de vários grupos.

Selecione um grupo à esquerda ou crie um novo.

Motores

Ordene por prioridade — se a franquia do primeiro esgotar, o próximo assume (fallback automático). Use ▲/▼ para reordenar.

Configurações globais

Valem para todos os projetos que não definirem override próprio.

Notificações externas

Envie os eventos do Praxis para Telegram, Discord, Slack, Google Chat ou um webhook próprio. Configure os canais e os eventos notificados por padrão — cada projeto pode personalizar quais recebe.

Tokens de API

Para o sistema de chamados e integrações. O valor aparece uma única vez na criação.

Usuários e acessos

Cadastre quem usa este Praxis e defina o que cada um pode fazer. O acesso básico é sempre visualizar; papéis concedem as demais capacidades.

Selecione um usuário à esquerda ou cadastre um novo.

Papéis

Um papel é um conjunto de permissões do catálogo. Vincule papéis aos usuários na tela Usuários.

Selecione um papel à esquerda ou crie um novo.

Grupos de usuários

Cada grupo define o motor e o modelo usados nas Consultas dos seus membros — dá para dar um modelo mais leve/barato a produto e suporte, já que a consulta só explica comportamento (não produz código de produção). Vincule usuários ao grupo na tela Usuários.

Selecione um grupo à esquerda ou crie um novo.
